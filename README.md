# Janitorial Protocol

The trash mafia is on the hunt, but you’ve got a mop and a mission...


# Controls

WASD to move

Space to jump

Alt+1 to use the trash picker

Alt+2 to use the broom

Shift to sprint

Left click with broom to attack

E while looking at trash or bin to collect/deposit,
